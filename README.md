# Final Project - Emotion Detection Application

An AI-based web application developed using Python, Flask, and the IBM Watson NLP Emotion Detection library.

## Project Description
This application analyzes user-provided text to detect underlying emotions including anger, disgust, fear, joy, and sadness, and determines the dominant emotion.

## Features
- Emotion analysis powered by IBM Watson NLP API
- Formatted output display
- Comprehensive unit testing suite
- Full error handling for invalid/blank inputs (HTTP status 400)
- Flask web interface
- Pylint-compliant Python code (10/10 score)
